## 第三轮打磨（提交 eb71c3b）

**方法论修正**：同一个 `?match=` 复用的 World 会在几分钟后换天气，前后截图可能
一张黎明一张深夜，A/B 完全不可比。现在每张图用**全新的 match 号**，并确认
sidecar 的 `modifier` / `modifierHour` 一致才做对比。白昼 07:00 的号：
`fx-12 / fx-19 / fx-27 / fx-36 / fx-50 / fx-53 / fx-56 / fx-57 / fx-66 / fx-69 / fx-80 / fx-87`。

- **屋顶浮空 0.4–1.6m**：`SHELLS` 手写 `top` 与地图墙高七栋全不一致。
  `village-assets.ts` 新增 `measureWalls()`：按"每个高度累计墙面长度"投票取墙顶，
  同时得到真实墙体轮廓；屋顶压在上面，檐板/角柱/踢脚贴真实轮廓。
- **立面构件**：`buildFacade()` 每栋 12 个盒子合并成 2 次绘制（檐板一圈、四角柱、
  石砌踢脚）。都不跨门窗洞口，所以不需要知道洞口位置。
- **屋顶同色**：`ink.ts` `comicWoodSurface` 瓦片分支末尾 `*= vec3(0.58,0.62,0.70)`；
  `VILLAGE_COLORS.roof` → `0x3d4249`。关卡坡屋顶是 `wood` 盒刷，改色只能在这里做。
- **枯树**：分叉必须沿 `(−cos·cosAng, −sin, −cos·sinAng)` 偏移（旧代码只减 X，
  侧枝全飘在半空）；枝条 4m 长近乎水平 → 0.95→0.48 倍、下垂 0.34–0.80；树干径向
  抖 5cm + 粗残桩 + 两根劈裂木刺。标签 `['tree','dead']` 之前归 `foliage` 表面
  （树皮上印叶簇），`render.ts` `stylizeGenerated` 现在让 `dead` 走 `wood`。
- **两套枯树并存**：`loadNature()` 在 `generatedTrees` 为真时直接 return，永远走不到

- **墙根荧光绿小棍 = 程序化芦苇**：落位条件 `wetness<0.08 && rng()>0.2` 写反了

- **护堤砖纹**：砌层沿 X 沉降 ±9cm、每行错缝随机、每块缝宽单独哈希、灰缝对比

## 第四轮打磨（提交在案：门/檐下封板/阳台误用）

**方法论**：先按 7 栋房子逐一近距离 GPU 实拍，找"最像没做完"的一处；不确定某个
色块是不是自己加的构件时，把材质临时染色拍一张（品红）—— 本轮用它排除了
"门洞亮格子"（其实是屋内被天光照满）和"檐下石砌色块"（其实是圆瓦瓦当的背面）。

- **门洞是亮的**：`DoorFrame_Flat_WoodDark.gltf` 只有 108 顶点、一圈空框；屋内被
  半球环境光照满（toon 不遮挡），所以 7 栋房子的门洞都是一块发亮的墙。
  `village-assets.ts` 新增 `buildDoor()`：五块竖板（缝 1.4cm）+ 背板（必须，
  否则缝透白）+ 两道铁门带 + 门楣 + 门柱 + 石础 + 门槛石。门扇 `uz=-0.2`，
  因为门框比墙面内凹 0.15–0.25m。
- **`doorBasis()`**：门朝哪按"离哪面墙最近"判定，不再读手写 `door.rotY`
  （那个角度只描述门框模型自己怎么转）。`pushOriented()` 提供门局部坐标。
- **阳台误用**：`SHELLS[0]` 的 `Balcony_Simple_Straight` 被 `place()` 按地面高度
  摆成一道挡在门口的栏杆；一层房子没有阳台，删掉。
- **屋檐**：`buildEaveFascia()` 沿屋顶自身轮廓加 30cm 封檐板（盖住圆瓦锯齿瓦口）
  + 檐下封板（`roofBase-0.03`，厚 8cm，封住出檐底面翻出来的瓦当背面）；
  檐板 22×22 → 12×16cm，避免两道平行黑带。
- **雨棚**：`PORCH_MIN_CLEARANCE = 1.05`，只有谷仓（墙顶 4.8）与磨坊（6.0）有。
  斜撑改成给两个端点反算长度/倾角（第一版手填三个量，上端悬空 15cm）。
- **芦苇**：逐丛 `HSL(0.22, .42-.62, .36-.50)` → `HSL(0.20, .32-.48, .30-.42)`，
  直射光下不再荧光绿。
- 验证：348/348；冒烟 7 步；1080p quality avg 16.67 / p99 16.8 / hitches 0
  （`docs/perf/polish5-marsh-quality-1080.json`）；Chrome 残留 0。
- 白昼参考天气：`match=fx-303` = modifier 7（07:00，fogScale 0.85）；
  `fx-202` = modifier 5（晨雾 1.5，会糊掉细节，不适合做画质判据）。
- 未做：室内与室外同亮（缺室内光照模型，门洞/窗洞看进去都是亮空房）；
  关卡自带平屋顶盒刷仍被 GLB 屋顶包着；地面背光像素只有 27 级动态范围。

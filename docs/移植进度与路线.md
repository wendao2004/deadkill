## 1. 已完成

### 渲染正确性（P0）

| 问题 | 修复 |
|---|---|
| Bloom 上采样用加法，光晕能量随 mip 层数膨胀 | 改 NormalBlending + alpha=uWeight（能量守恒 lerp） |
| Bloom 阈值在未曝光空间，换曝光就换效果 | 预过滤样本先乘曝光，合成时先曝光后叠 bloom |
| 接触阴影强度乘两次（shader 一次 + composite 一次） | `uContact` 改为 0/1 开关，强度只乘一次 |
| 武器层在 bloom 之后合成，枪口闪光不发光 | 新增全分辨率 `sceneRT` + COMBINE pass，武器先合成再 bloom |
| 阴影相机跟随玩家无 texel 对齐，边缘爬行 | 光空间 right/up 量化到 texel，只平移不转向 |
| 全仓无 shader 预编译，首帧/首次开枪卡顿 | `Renderer.prewarm()`：compileAsync + 真实渲染一帧 + 后处理各一次，失败降级 |

文件：`client/src/postfx.ts`、`client/src/atmosphere.ts`、`client/src/render.ts`、`client/src/game.ts`。

## 2. 硬约束（改之前先看）

1. **服务端权威**：位置、命中、伤害在服务端算；移动/相机改动必须走 `shared`，客户端预测与服务端逐字同源。
2. **0.4m 网格**：所有“能站上去”的盒顶必须是 0.4 的整数倍；悬空薄片不受限。
3. **盒子数量**：`MAX_BOXES = 1100`（`tests/level.test.ts`）。沼泽当前 998；视觉细节应走客户端视觉壳，不要全塞进 `level.boxes`。
4. **视觉/判定同源**：`level.boxes` 同时驱动渲染、Rapier、穿透、小地图；不能用纯视觉网格替换碰撞盒，否则出现“打中不算 / 隐形墙”。
5. **同源分发**：CSP `default-src 'self'`，外部资产必须同源；不能 CDN 直链。
6. **网络节奏**：60Hz tick / 20Hz 快照 / 90ms 插值；新增状态位要升协议版本。

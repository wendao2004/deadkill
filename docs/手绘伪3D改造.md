# 手绘伪 3D 改造（2026-11-08）

> 决策：**放弃 PBR 写实档作为默认画风，回到手绘伪 3D**。
> 程序化几何 + PBR 光照的短板是"低模 + 真实光照 = 一眼假"；
> 而手绘风格的信息量来自轮廓、色阶、排线与构图，恰好是程序化几何擅长的。

## 0. 一句话目标

画面读起来像**纸上画出来的夜猎场景**：平涂色块、墨线勾边、暗部排线、
纸张颗粒、手绘天空；但玩法、碰撞、网络、判定全部不变。

## 1. 非目标

- 不改成 2D 俯视/横版。玩法仍然是第一人称 3D，只是**着色与构图**手绘化。
- 不引入贴图资产（手绘感靠程序化墨线/排线/纸纹，不靠贴图）。
- 不推倒已有的 ink/outline 系统：它本来就是为这个画风写的。

## 2. 已经落地（本轮）

### 2.1 画风开关

`render.ts` 的 `realistic = false`：所有 `surfaceMaterial` 走 `toonMaterial`，
武器/猎人/怪物/关卡重新获得四级色阶、墨线壳与排线。写实分支保留可回滚。

### 2.2 程序化 GLB 的卡通化

- `stylizeGenerated()`：把 GLB 的 `MeshStandardMaterial` 换成卡通材质 +
  顶点色，材质家族按用途给（树 → foliage、建筑 → wood、石头 → stone）。
- `instanceAsset()` 支持 `outline`：每个实例再挂一份同矩阵的
  `InstancedMesh` 画背面墨线外壳，只多一次 draw call，不复制顶点。

### 2.3 树

- 松树宽度从 4.4m 收到 2.7m、层数加密：之前是"几片大伞"，现在是"细高的松"。
- 树干仍保持 0.94m 直径，完整包住关卡里 0.8m 的树干碰撞盒。

### 2.4 草

- 从均匀撒点改成**草窝**：110 个窝，每窝 8~18 簇；单簇更小。
- 手绘场景里的草是成片长的，均匀撒点会读成"地上铺了一层草皮"。

### 2.5 纸张颗粒

`postfx.ts` 的合成 pass 增加 `uPaper`：两层低频斑 + 一层细纤维，乘性压暗
并叠极轻的暖色偏移。用 `gl_FragCoord`，纸张本身不动。

### 2.6 构图

- 松林营地加土路装饰片（noCollide），把南入口 → 营地 → 锯木厂/伐木坡串起来。
- 路是最便宜的构图工具：告诉玩家往哪看，也把空地切成有意义的块。

## 3. 下一步（按优先级）

1. **手绘天空**：现在天空仍是物理渐变。改成 3~4 条色带 + 手绘云/月亮剪影，
   并把远景树线画成一层剪影（billboard 或半透明平面）。
2. **武器/猎人材质**：确认卡通档下的假高光与rimin 参数，避免武器读成灰板。
3. **墨线宽度分级**：近景 2.4px / 中景 2.0px / 远景 1.6px，避免远处糊成黑块。
4. **区域构图**：每张图补 1~2 个"能当封面"的地标（教堂钟楼、锯木厂水车、
   车站水塔），并用土路/围墙把视线收束到地标上。
5. **动作系统**：滑铲取消（站起保留动量）、落地缓冲、翻越后接奔跑的衔接。

## 4. 验收

- 三包 typecheck 0 error；全部测试通过；vite build 通过。
- 线上实机：手绘档进入对局无 shader 报错；帧时间不高于写实档。
- 视觉检查：树不再"一片大伞"；草地成簇；轮廓线在暗部能读出来。

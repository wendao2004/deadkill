# 3D 地图编辑器

打开方式：

- 本地开发：`http://localhost:5173/editor.html`
- NAS：`https://192.168.1.112:9443/dead-kill/editor.html`

一个 three.js 的 3D 视图 + 属性面板。数据模型和游戏完全同源，导出的就是
可以注册进 `LEVELS` 的 `LevelDef`。

## 相机与操作

| 操作 | 键 |
|---|---|
| 旋转视角 | 右键拖动 |
| 平移 | 中键拖动 |
| 缩放 | 滚轮 |
| 选择 | 左键点击（选择工具） |
| 画盒刷 | 选择「画盒刷」后在网格上拖一个矩形 |
| 放标记 | 选出生点/巢穴/线索/撤离/区域/水面，左键点地面 |
| 删除 | Delete |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Y |
| 变换模式 | W 移动 / E 旋转 / R 缩放（选中模型时） |

网格吸附 0.4m（角色自动上台阶的高度，也是关卡硬约束）。

## 工具

- **盒刷**：矩形 + 底面/顶面高度。右侧面板可改中心、半宽、高度、旋转、材质，
  以及 `noCollide`（纯装饰）和 `noRender`（只碰撞不渲染的隐形骨架）。
- **标记**：
  - 出生点（绿柱）、巢穴（红锥，grunt/gunner/hound）、线索（黄八面体，可写文案）、
    撤离（蓝方块，可命名）、区域（地面圆环，可调半径）、水面（蓝色平面）。
- **变换**：选中模型后 W/E/R 切换移动/旋转/缩放，gizmo 直接拖；也可以右侧改数值。

## 导入自己的模型

点右上角「导入模型」，选 `.glb`（推荐）或 `.gltf`：

- 模型会出现在原点，用 W 移动到位置、R 缩放、E 旋转；
- 右侧面板可以「下载模型文件」，方便你把它放到项目里；
- 导出 `.ts` 时，这些模型会写进 `heroes`：
  `{ asset: 'log_cabin', x, z, y, rotY, scale }`。

**部署约定**：把模型文件放到 `client/public/models/imported/`，
文件名必须是 `<asset>.glb`（asset = 导入时去掉扩展名的文件名）。
游戏启动时会先查生成资产清单，查不到就去 `models/imported/<asset>.glb` 加载；
加载失败只跳过这个模型，不影响整张图。

> 静态模型可以直接实例化；带骨骼动画的模型目前按静态摆放（InstancedMesh 不支持蒙皮）。

## 校验

点「检查」会按 `tests/level.test.ts` 的同一套规则检查：

- 盒刷 ≤ 1800；
- 可攀爬盒顶落在 0.4m 网格上；
- 线索正好 3 条、巢穴 ≥6、出生点 ≥4、撤离 ≥2、区域 ≥4；
- 每条线索 14m 内有巢穴；
- 出生点离所有巢穴/线索 ≥35m；
- 撤离点离地图中心 ≥60m。

## 导入游戏

1. 「导出 .ts」得到一个完整的 `LevelDef` 文件；
2. 放进 `shared/src/maps/`；
3. 在 `shared/src/level.ts` 里 import 并加进 `LEVELS`（导出文件头部注释里有现成的两行）；
4. 把导入的 `.glb` 放进 `client/public/models/imported/`；
5. `pnpm test`，然后重启服务端 —— 菜单的地图列表会自动多出这张图。

「保存到浏览器」把草稿放进 localStorage；「导出 JSON」可以存档或发给别人，
「导入 JSON」读回来继续画（模型需要重新导入）。

# 地图编辑器

打开方式：

- 本地开发：`http://localhost:5173/editor.html`
- NAS：`https://192.168.1.112:9443/dead-kill/editor.html`

它是纯 2D canvas 页面，不加载 three/rapier，打开就是一个空白网格。

## 工具

| 工具 | 操作 |
|---|---|
| 选择 / 移动 | 点选盒刷或标记，拖动移动；右侧改数值 |
| 画盒刷 | 按住左键拖一个矩形；松手生成一个盒刷 |
| 出生点 / 巢穴 / 线索 / 撤离 / 区域 / 水面 | 点一下放一个标记 |
| Delete | 删除选中 |
| Ctrl+Z / Ctrl+Y | 撤销 / 重做 |
| 滚轮 | 缩放（以鼠标为中心） |
| 中键拖动 / 空格+拖动 | 平移 |

网格吸附 0.4m（角色自动上台阶的高度，也是关卡硬约束）。

## 右侧面板

- 选中盒刷：中心、半宽、底面/顶面高度、旋转、材质、`noCollide`、`noRender`。
- 选中标记：位置；巢穴可选 grunt/gunner/hound，撤离/区域可命名，线索可写文案。
- 地图设置：id、名称、群系、半边长、地面 Y、地面材质、雾色/雾密度。

`noRender` 用于"只碰撞不渲染"的隐形骨架（GLB 建筑的墙）；`noCollide` 用于
纯装饰片（土路、横梁）。

## 校验

点「检查」会按 `tests/level.test.ts` 的同一套规则检查：

- 盒刷 ≤ 1800；
- 可攀爬盒顶落在 0.4m 网格上；
- 线索正好 3 条、巢穴 ≥6、出生点 ≥4、撤离 ≥2、区域 ≥4；
- 每条线索 14m 内有巢穴；
- 出生点离所有巢穴/线索 ≥35m；
- 撤离点离地图中心 ≥60m。

## 导入游戏

1. 「导出 .ts」得到一个完整的 `LevelDef` 文件；
2. 放进 `shared/src/maps/`；
3. 在 `shared/src/level.ts` 里 import 并加进 `LEVELS`（导出文件头部注释里有现成的两行）；
4. `pnpm test` —— 关卡约束会再替你跑一遍；
5. 重启服务端，菜单的地图列表会自动多出这张图（`LEVEL_IDS` 驱动）。

「保存到浏览器」把草稿放进 localStorage；「导出 JSON」可以存档或发给别人，
「导入 JSON」读回来继续画。

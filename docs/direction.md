# DEAD KILL · 方向定调

## 一句话幻想

1890 年路易斯安那沼泽，你是靠赏金过活的猎人：带一盏灯、一把老枪和一枚
护身符走进腐化沼泽，在别的猎人和怪物之间抢下赏金，再从三个撤离点之一活着出去。

## 三根支柱

1. **信息稀缺**：能见度低、线索要读、声音会暴露位置；先看见对方的人赢一半。
2. **一枪致命**：伤害按部位、距离、穿透层数结算；倒地 30 秒可被队友救起。
3. **声音即情报**：枪声、脚步、换弹、怪物嚎叫都带距离/遮挡/室内外分层。

所有系统取舍回到这三句。PvPvE、Boss、合同、天气都是支柱的放大器，不是新支柱。

## 视觉方向

只允许三组颜色角色 + 一个重复母题：

| 角色 | 颜色 | 用途 |
|---|---|---|
| 环境主色 | 油墨黑 `#0c0b0a` / 冷板岩 `#2a3138` | 天、地、建筑、所有描边 |
| 信号色 | 骨白 `#d8cfba` + 灯火橙 `#d99a4a` | 可交互、弹药、准星、强调 |
| 危险色 | 干血红 `#7d2b22` + 病态黄绿 `#9aa845` | 受伤、低血量、毒/腐化、Boss |

- 字体：展示用 Arial Black / Impact；标签与读数用等宽 `--font-mono`；正文系统 UI。
- 母题：**手绘墨线 + 排线 + 纸纹**。所有材质走同一套 4 级色阶与墨线，不做 PBR 默认。
- 界面风格：沉浸式战术终端 —— 细线、低饱和、无硬阴影、无圆角贴纸。
- 禁止：外链字体/图片；PBR 写实默认；与墨线冲突的柔和阴影/玻璃拟态。

## 约束

- 浏览器端 TypeScript + Three.js r186；服务端 Fastify + Rapier3D，服务端权威。
- 共享 60Hz 模拟、20Hz 快照；客户端预测/和解 + 延迟补偿。
- 无外部美术/音频资产：几何、纹理、音效全部运行时生成。
- 部署目标：宿主容器 512MB 上限；世界懒创建，空房/空世界回收。
- 客户端输入：键鼠为主；指针锁不可用时降级为移动鼠标转向。
- 触屏/手柄：**尚未支持**（见架构文档的已知缺口）。
- 验收：`?seed/?dt/?cam/?shot/?q/?show` 固定；截图、冒烟、基准可复现。

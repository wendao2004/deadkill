# 渲染升级：从直出卡通到 HDR 管线

> 2026-11-05。目标是把"画面糊、枪械简陋"这两个最直观的问题从根上解决，
> 同时保留《猎杀：对决》式的暗夜卡通墨线风格。

## 1. 旧管线为什么会糊

旧实现把世界直接画到 canvas：

- `antialias: false`，没有任何几何抗锯齿；
- 动态分辨率最低 0.55，而且**缩小的是 canvas 本身**，再由 CSS 拉满全屏 ——
  浏览器的双线性拉伸会把整幅画面（包括枪管边缘）摊成两三个像素的斜坡；
- `renderer.toneMapping = NoToneMapping`，高光被 8bit framebuffer 硬削平，
  没有泛光、没有曝光，暗部与亮部只能二选一；
- 没有实时阴影，箱子/角色/怪物像贴纸一样浮在地上；
- 武器和世界共用同一张低分辨率画布，降分辨率时枪跟着一起糊。

## 2. 新管线（`client/src/postfx.ts`）

每帧的顺序：

1. **世界 HDR RT**：`RGBA16F` + MSAA 4x，分辨率 =
   `CSS × devicePixelRatio × renderScale`。场景在线性光里渲染，
   材质阶段不做 tone mapping。
2. **武器 HDR RT**：同样 `RGBA16F` + MSAA 4x，但**始终按原生分辨率**，
   背景透明、独立深度。武器不再穿墙，也不会跟着世界一起降分辨率。
3. **Bloom**：13-tap 降采样 + 软膝阈值（只让超过显示白的部分发光）+
   9-tap 帐篷上采样，5 级 mip。月光、火光、曳光弹、枪口闪光的线性亮度
   > 1，所以它们会发光，而普通墙面不会。
4. **合成**：`world × (1 − view.a) + view.rgb`（MSAA resolve 的预乘 alpha），
   曝光、线性光 cos⁴ 暗角、AgX 色调映射、显示空间轻调色、亮度域对比自适应
   锐化（抵消降分辨率后的双线性软边）、静态颗粒与抖动。
5. **FXAA**：在输出分辨率上做一次紧凑的边沿滤波，写回 canvas。

关键取舍：

- **画布永远是原生分辨率**，只有世界 RT 会缩放。`setRenderScale` 不再改
  `gl.setPixelRatio`，所以不会出现"CSS 拉伸"那一层模糊。
- **AgX 而不是 ACES**：ACES 的高光肩膀在夜戏里会发洋红；AgX 的
  log 归一化 + punchy look 能把火光、月盘压回可读的暖白。
- **锐化在色调映射之前、只动亮度**：色度不参与，避免高对比边缘出现彩边。
- **静态颗粒**：不跟时间抖动，避免夜戏里满屏"电视雪花"。

## 3. 实时阴影

`atmosphere.ts` 的月光现在是 `castShadow` 的主光：

- 正交阴影相机 ±52m，2048²，PCFSoft，`normalBias 0.035`（平面卡通几何
  必须靠 normalBias 才不漏光）；
- 阴影相机每帧跟着玩家平移，方向不变 —— 100m 范围 5cm/texel，
  阴影边沿才有轮廓；覆盖整张 90m 地图会糊成一片灰；
- 关卡合并网格、角色、怪物、装饰中的单面实体都 `castShadow`；
  墨线外壳、水面、雾墙、血条、双面草叶不投影（它们只会贡献噪点）。

## 4. 材质细节（`client/src/ink.ts`）

原有屏幕空间排线、世界空间污渍、雨痕、接触压暗全部保留，新增：

- **世界空间三平面材质细节**：按主导轴选投影，给固有色乘上
  `stone`（砖缝/石板）、`wood`（木纹/板缝/节疤）、`metal`（拉丝/锈斑/麻点）、
  `mud`（湿斑/积水/砂砾）、`foliage`（叶簇）五种程序化图案。幅度压在
  ±16% 左右，砖缝/节疤最多 30%，不改变 4 级色阶的光照结构。
- **距离淡出**：细节图案在 16~52m 内渐隐。程序化图案没有 mip 链，
  远墙的砖缝在移动时会闪；低频污渍不淡出，所以远景仍有材质感。
- **假高光 + 轮廓光**：用 44 次幂的 Blinn 高光和菲涅尔边缘，方向由
  `INK_SHARED.keyDir` 共享。世界材质跟随月光；武器场景在 `render()` 里
  临时切成固定的"棚拍"方向，所以无论玩家面朝哪边，枪身倒角上的高光位置
  都稳定 —— 这是金属读成金属、而不是一块灰板的关键。

## 5. 武器模型（`weapon-kit.ts` + `weapon-models.ts`）

从"直角盒子 + 圆柱"换成一套程序化硬表面工具箱：

- 所有盒子都是 `RoundedBoxGeometry`（0.3~1.5mm 倒角），挤出件带 bevel，
  管件用 `latheZ` 车削，端面有圆冠；
- 温菲尔德/消音卡宾/神射手：挤出的机匣侧板、抛壳口、装填门、杠杆环、
  扳机护圈、M-LOK 护木、真膛口（内管退进枪口 8mm）、皮卡汀尼级瞄具、
  光学镜筒/镜座/塔轮、消音器滚花；
- 双管霰弹：并排双管 + 上肋条 + 铰链销 + 双外露击锤 + 双扳机 + 防滑护木；
- 柯尔特转轮：车削转轮、六个弹巢端面、侧壁凹槽、抽壳杆、黄铜背带；
- 猎刀：挤出刀身 + 真实倒角 + 亮刃 + 血槽 + 铆钉护手；
- 四把武器合计约 42k 三角形；静态零件按材质合并成 10~18 个 Mesh，
  击锤/转轮/刀光保持独立，由原有动画标量驱动。

手部保留程序化手套（掌、四指两节、拇指、腕口、前臂），并整体缩到 0.82：
第一人称里手离相机只有 0.4m，等比放大的一只"巨手"会盖住整把枪。

## 6. 角色模型与浏览器内烘焙

远端玩家从"身体盒子 + 球头"换成了程序化猎人（`client/src/hunter.ts`）：

- 宽檐帽、长大衣、腰带/斜挎弹药带、背包 + 铺盖卷、靴子、手套、横抱的杠杆步枪；
- 几何按"身体 + 左右腿"分组，腿绕髋关节摆动；步行相位由远端插值速度驱动，
  没有骨骼/蒙皮 —— 5m 外的观察距离，摆动比解剖精度重要，也更省；
- 材质仍走 `MeshToonMaterial + applyComicInk`（阶梯光照、排线、世界空间细节、
  假高光、轮廓光），和世界/武器是同一套着色器。

**浏览器内烘焙**（`client/src/baked-textures.ts`）：

- 启动时在 128×128 Canvas 里生成两张**灰度细节图**——布料（经纬、污渍、缝合线）
  和皮革（斑驳、褶皱、双排缝线）；
- 作为 `MeshToonMaterial.map` 挂到角色材质上，材质 `color` 仍负责色相，所以
  同一张图能给外套/裤子/背包用不同颜色；
- 运行时只是一次普通纹理采样，没有每帧程序化 ALU；要搬到别的引擎，可以把
  canvas 导出成 PNG/KTX2 再导入。

## 7. 移动/视角的插值

旧实现把 60Hz 的预测位置直接交给相机，144Hz 屏幕上位置每 16.7ms 跳一次，
读起来就是"移动卡卡的"。现在：

- `fixedUpdate` 前后各取一次脚底位置，渲染时用 `kernel.clock.time.alpha`
  在 `prev/curr` 之间插值；大幅位移（服务器校正/传送）直接吸附；
- 眼高单独指数平滑，蹲/起立时镜头不跳；
- 远端猎人的腿摆由插值后的速度驱动；
- 自适应分辨率/画质**只降不升**：连续 1 秒明显掉帧才降一次，避免"升分辨率
  → 又掉帧 → 再降"的周期性顿挫；泛光金字塔不再随 renderScale 重建。

## 8. 性能与旋钮

冒烟测试（1280×720，SwiftShader）实测一帧：

```
calls 92 · triangles 121920 · lines 36384 · programs 19 · geometries 44 · textures 13
```

其中三角形包含阴影 pass 与全部后处理 pass。真实 GPU 上会低得多，但预算
仍然可控（关卡约 1.2 万盒面 + 装饰 + 武器 + 阴影）。

可调项：

| 旋钮 | 位置 | 说明 |
|---|---|---|
| `renderScale` | 设置面板 / `Renderer.setRenderScale` | 只缩世界 RT；画布始终原生 |
| 自动降分辨率下限 | `game.ts` 的 `adaptResolution` | 从 0.55 提到 0.72，宁可掉帧不糊 |
| MSAA 采样数 | `new PostFX(gl, { samples: 4 })` | 弱 GPU 可降到 2 或 0 |
| 阴影贴图 | `atmosphere.ts` 的 `moon.shadow.mapSize` | 2048²；改成 1024² 可省一半带宽 |
| Bloom 强度/阈值 | `postfx.ts` 的 `PostSettings` / `BLOOM_THRESHOLD` | 默认 0.07 / 1.0 |
| 曝光 | `Renderer.setBrightness` | 设置面板亮度直接乘在 HDR 曝光上 |
| 画质档 | 设置面板 / `Renderer.setQuality` | 自动/性能/均衡/高清；核显/软件渲染自动进性能档 |

画质档的 GPU 探测、强制独显的系统/浏览器设置，以及 CMP 30HX 这类
"核显输出 + 无显示输出矿卡"的说明，见 `docs/显卡与性能.md`。

## 9. 硬核机瞄与刀的特效边界

- **取消屏幕准星**：`#crosshair` 保留 DOM 但 `display:none`；设置面板里的
  准星颜色/大小/不透明度一并撤掉。镜筒分划（`#scope`）仍然保留，因为它是
  光学瞄具的一部分。
- **开镜俯仰归零**：机械瞄具的照门/准星连线现在与相机视轴严格共线，
  开镜时两点重合在屏幕中心；`ADS_FOV_PULL` 20→24，前准星片/照门耳加粗，
  前准星加了一颗自发光亮珠。开镜时相机滞后彻底关闭，避免瞄具滑出中心。
- **刀不是枪**：客户端收到 `weaponId === 猎刀` 的 Shot 事件时不再画曳光、
  不再沿视线补墙面弹着点、不再放枪声；命中反馈仍由 Hit/MonsterHit 提供
  （血雾 + 刀切声）。

## 10. 还没做 / 已知限制

- 没有 TAA、SSR、SSAO。当前靠 MSAA + FXAA + 锐化；动态物体没有时域抗锯齿。
- Bloom 只作用于世界层，武器层不参与泛光（枪口星芒是自绘的加色面片）。
- 阴影是单级联、跟随玩家的正交阴影，不是真正的 CSM；超远景不投。
- 程序化材质细节按世界坐标取，斜面对墙的图案会有轻微拉伸。
- 手部仍是风格化几何，不是骨骼/蒙皮；换弹时手指不会逐节弯曲。

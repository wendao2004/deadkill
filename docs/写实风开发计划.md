# 写实风开发计划（第三档：全面写实，独显专属）

> 2026-11-06。决策：采用全面写实路线，**放弃核显/软件渲染支持**。
> 本文是执行计划，不是画质承诺书：目标、边界、验收指标和已知坑都写在这里，
> 后续每一步都按这里的验收项检查。

## 0. 目标与非目标

**目标**

- 独显 1080p、quality 档 60fps（p95 帧时间 ≤ 16.7ms）。
- 近景（枪、手、猎人 0.3–5m）做到准写实：PBR 材质、方向性环境反射、
  法线/粗糙度细节、接触阴影。
- 关卡表面写实：944 个盒刷不改形体，用米制 UV + PBR 贴图 + IBL + GTAO。
- 角色/怪物最终换成 GLTF SkinnedMesh + 骨骼动画，武器换 UV 展开后的 PBR 资产。
- 敌人保留一条细轮廓（1.2–1.4px），只作为暗夜 PvP 的识别通道。

**非目标**

- 照片级写实、硬件光追、Nanite/Lumen、compute 降噪、froxel 体积雾。
- 核显/软件渲染可玩。performance 档仅作为开发回退与低端独显兜底保留。
- 用 GLB 替换 `level.boxes`。盒子同时驱动渲染、Rapier 碰撞、穿透、小地图，
  换形体会出现「打中不算 / 隐形墙」，只能做「盒刷碰撞 + 表面材质 + hero 视觉件」。

## 1. 硬约束（每次改动前先看这一节）

1. **视觉与碰撞同源**：`level.boxes` → 渲染、[server/src/world.ts](../server/src/world.ts)
   的 Rapier、`shared/src/penetration.ts`、`client/src/surfaces.ts`、
   `client/src/map.ts`。不要改这份数据。
2. **60Hz 模拟 / 20Hz 快照 / 90ms 插值**：TAA 没有逐物体运动矢量，
   必须自写相机重投影 + reactive mask，并保留 MSAA+FXAA 回退。
3. **世界/武器双 RT**：世界可降分辨率，武器恒原生。任何新的屏幕空间效果
   都要决定作用在哪一层；武器层全分辨率，成本按全分辨率另算。
4. **NAS 分发**：CSP 是 `default-src 'self'`，资产必须同源；`fastifyStatic`
   目前没有 immutable 缓存，资产化之前先补缓存与增量同步。
5. **资产成本**：渲染工程之外，4 把枪 UV/贴图、猎人骨骼、7 种怪骨骼动画、
   5 个群系道具是 25–40 人周，必须在 M5 之前单独排期。

## 2. 阶段与验收

### M0 基线（1 周）

- `renderer.info`（calls/tris/lines/programs/textures）+ 固定机位 3 分钟
  帧时间 p50/p95 + luma 中位数/95 分位探针。
- 独显 / 核显 / SwiftShader 各录一份基线；统一 README、docs 里的口径漂移
  （自动分辨率下限、30Hz/60Hz、PCFSoft）。
- 验收：同一机位截图可重复；performance 档 92 calls / 19 programs / 13 textures
  不变；luma 能复现中央区 ~51/112。

### M1 深度与环境光（3 周）

- worldRT 挂 `DepthTexture`（`DepthFormat` + `UnsignedIntType`，MSAA 深度由
  three 的 `resolveDepthBuffer` 解析）。
- 半分辨率/全分辨率屏幕空间接触阴影（8–10 步 view-space raymarch），
  只乘世界层，强度 ≤0.4。
- 天空探针：CubeCamera 捕获 atmosphere 天空球 → `PMREMGenerator` →
  `scene.environment`；世界层手写反射用原始 CubeRenderTarget，PBR 层用 PMREM。
- 曝光/环境光重标：先抬亮度到中央区 70–85 / 95 分位 ≥140，再上 AO。
- 验收：箱脚/角色脚出现 2–4px 方向性接地暗部；墨线外圈无暗环；
  1080p 独显 p95 ≤ 15.5ms；无 >100ms 的 shader 编译卡顿。

### M2 PBR 主体（7 周）

- 新建 `client/src/materials.ts` + `client/src/uv.ts`：toon/PBR 双分支、
  `TILE_METERS`、`isShadowCaster()`。
- `buildLevel` 合批前写米制 box-projected UV；`props.ts` 不再删 uv。
- `baked-textures.ts` 扩到 512² albedo/normal/ORM 五族。
- 武器 11 套材质并成 6 套 PBR；猎人/怪物切 PBR（暂不做骨骼）。
- 加载门后 `renderer.compileAsync` 预编译。
- 验收：944 盒刷与碰撞不变；calls 150–200、programs ≤45、textures ≤40；
  ADS 照门-准星共线误差 ≤1px；首次开枪无同步编译卡顿。

### M3 屏幕空间与风格退场（4 周）

- 半分辨率 GTAO（复制 GTAOShader/PoissonDenoiseShader 自建 pass，
  `setGBuffer(depth, undefined)` 走深度重建法线）。
- 自写 TAA：Halton 抖动、上一帧 viewProj 重投影、YCoCg clipping、
  1/8 分辨率 reactive mask；传送/切图/ADS/命中定格 reset。
- 写实档去掉关卡墨线壳/EdgesGeometry/排线，只保留敌人轮廓。
- 验收：移动怪拖影 ≤2px；GTAO 无闪烁白边；浓雾/薄雾两档 40m 剪影可辨；
  12 怪 + 16 猎人 p95 ≤15.5ms。

### M4 阴影与大气（3 周）

- 单级联 2048 阴影按 PBR 法线重测 bias/normalBias；±36m → 3.5cm/texel。
- CSM 只有在 toon 档彻底移除后才可以接（`CSM.js:189` 会全局替换
  `ShaderChunk.lights_fragment_begin/lights_pars_begin`）。
- 高度雾 + 朝月亮的屏幕空间光轴；水面改平面反射 + 深度折射。
- 验收：逆光/侧光下阴影无 acne、无 peter-panning；水面反射方向正确；
  体积光成本 ≤2ms。

### M5 资产 gate（8–12 周）

- GLTFLoader/KTX2Loader/Meshopt + manifest + 预加载 + 404 回退。
- 猎人 1.8m SkinnedMesh + idle/walk/aim/hit/death 五剪辑；
  7 种怪 SkinnedMesh + AnimationMixer + LOD，保留 44 套池化。
- 武器 UV 展开与 PBR 三图；5 个群系 hero 道具。
- 服务端补 immutable Cache-Control 与压缩；部署改增量同步。
- 验收：猎人 1–3 draws / 20–40k tris；12 怪同屏 60fps；冷启动无 404；
  单图增量 <10MB；首包不因 sourcemap 膨胀。

### M6 收尾（2 周）

- 画质档重排（performance 仅兜底、balanced/quality 写实）、文档、
  回滚演练、性能回归表。

## 3. 已确认的 API 坑（来自 2026-11-06 对抗评审）

- `TAARenderPass` 没有重投影，不能当 TAA 用。
- `GTAOPass` / `SSRPass` / `BokehPass` 会自己 `renderer.render(scene)`，
  造成二次 draw；复制 shader 自建全屏 pass。
- `PMREMGenerator` 输出是 CubeUV 编码，不是 cube texture；世界手写反射
  要用原始 `WebGLCubeRenderTarget`。
- `CSM.js` 只有单一 `shadowMapSize`，构造时会全局替换 ShaderChunk。
- `layers` 同时过滤颜色和深度，不能只把墨线壳排除出深度。
- 墨线壳是 opaque 且 `depthWrite=true`，会在 AO/接触阴影里画暗环；
  写实档要么移除，要么单独 depth prepass。
- `PCFSoftShadowMap` 在 r186 已废弃，按 `PCFShadowMap` 调 radius/bias。
- `MeshToonMaterial` 没有 envMap 槽位；IBL 只对 Standard/Physical 生效。
- `transmission` 会触发额外场景渲染并破坏双 RT 合成，武器/水面禁用。

## 4. 当前进度

### 2026-11-06：M1 第一刀（地基已通）

已落地：

- `postfx.ts`：worldRT 挂 `DepthTexture`（DepthFormat/UnsignedIntType，
  MSAA 深度 resolve）；新增接触阴影全屏 pass（8 步视图空间 raymarch，
  输出乘世界层），performance 档自动关闭。
- `environment.ts`：clone atmosphere 天空球 → 128px CubeRenderTarget →
  PMREM；同时保留原始 cube 给以后的手写反射。武器场景
  `environmentIntensity = 1.0`，世界层 0.35。
- `render.ts`：武器与猎人材质走 `MeshStandardMaterial`（金属度 1 /
  粗糙度按旧 specular 映射），写实档不再给它们加墨线；阴影投射判定
  同时接受 Standard/Toon，避免换材质后静默丢影子。
- 武器 PBR 使用现有 128² 烘焙灰度图作 albedo 细节，法线/ORM 留给 M2。

验证：

- 三包 typecheck 0 error；`pnpm test` 195/195；vite build 通过。
- 无头 Edge（SwiftShader）实机进入对局：
  - performance 档：canvas 1280×720，无异常；接触阴影关闭，PBR 武器正常。
  - quality 档（强制）：无 shader 编译错误、无异常；接触阴影 pass 正常出图。
- 尚未做：真实独显帧时间基线（M0）、曝光/环境光重标（M1 剩余）、
  半分辨率接触阴影与 denoise（M1 优化）。

### 2026-11-06 续：M2 第一刀（关卡表面 PBR）

已落地：

- `pbr-textures.ts`：五族程序化 256² albedo/normal/roughness，同一高度场
  出三张图；米制平铺（泥 3.0m、石 1.2m、木 0.9m、金属 0.7m、叶 1.2m）。
- `render.ts`：合批前给 BoxGeometry 写**米制盒投影 UV**；关卡/地面改

  关卡墨线壳与 EdgesGeometry。
- PBR 材质加菲涅尔轮廓光（注入 `opaque_fragment`），补回暗夜剪影可读性，
  强度远低于原墨线。

  shadow acne。
- 自动画质改为：独显 → quality，核显/软件渲染 → balanced（仍然写实材质，
  不再自动退回 toon）；提示文案改成"不在支持范围"。

只保留法线/粗糙度微结构。等 M5 有 authored 贴图/UV 后再加回来——这是
程序化 albedo 与低模盒刷的结构性问题，不是调色能解决的。

验证：

- typecheck 0 error、195/195 测试、vite build 通过。
- 无头 Edge：quality 与 auto(balanced) 都能出图，无 shader 错误/异常；
  截图存在 `docs/screenshots/`。
- 仍需真实独显基线：SwiftShader 的 100–300ms 帧时间不代表 GPU。

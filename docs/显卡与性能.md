# 显卡、帧率与画质

## 先说结论

**网页不能选择用哪张显卡。** WebGL 的 `powerPreference: 'high-performance'`
只是给浏览器的一个提示，最终由操作系统、显卡驱动和浏览器决定。代码里也没有
任何 API 能"强制切到独显"。

所以 dead_kill 走的是两条路：

1. **能跑的机器尽量跑好**：启动时探测 GPU，核显/软件渲染自动进性能档，
   独显从均衡档起步；运行中再按实测帧时间升降档。
2. **想强制独显**：只能在 Windows / 浏览器 / 显卡驱动里设置（见下）。

## 怎么确认当前跑在哪张卡

游戏内右上角调试行现在会显示：

```
60fps · 24ms · tick 1234 · 核显/性能
```

- `核显` / `独显` / `软件渲染` 是 GPU 类别；
- 后面是当前画质档（性能 / 均衡 / 高清）。

更详细的信息：

- 浏览器控制台启动日志：`[dead-kill] GPU: ANGLE (NVIDIA ...)`；
- Chrome/Edge 地址栏打开 `chrome://gpu` 或 `edge://gpu`，看
  **GL_RENDERER** / **Graphics Feature Status**；
- 也可以在游戏控制台执行 `__dk.gpu`，会返回驱动报告的完整渲染器字符串。

## Windows：把浏览器指到独显

### 方法 A：Windows 图形设置（最通用）

1. 设置 → 系统 → 显示 → **图形**（Windows 10/11 都在这里）；
2. 添加桌面应用：`chrome.exe` 和/或 `msedge.exe`；
3. 点该应用 → 选项 → **高性能** → 保存；
4. 完全退出浏览器再重开（任务管理器里确认没有残留进程）。

### 方法 B：NVIDIA 控制面板

1. NVIDIA 控制面板 → 管理 3D 设置 → **程序设置**；
2. 添加 `chrome.exe` / `msedge.exe`；
3. 首选图形处理器 → **高性能 NVIDIA 处理器**；
4. 应用后重启浏览器。

AMD 显卡对应的是 AMD Software → 游戏 → 图形 → 为应用选择高性能 GPU。

### 方法 C：Chromium 启动参数 + 桌面快捷方式

把下面的命令存成 `.bat` 或快捷方式（按你的浏览器路径改）：

```bat
start "" "C:\Program Files\Google\Chrome\Application\chrome.exe" ^
  --force_high_performance_gpu --use-angle=d3d11 ^
  "https://192.168.1.112:9443/dead-kill/"
```

- `--force_high_performance_gpu` 是 Chromium 的 GPU 切换开关；
- `--use-angle=d3d11` 让 ANGLE 走 D3D11 后端（Windows 上通常最稳）；
- Edge 同样支持这两个参数；
- 有些 Chrome 版本/企业策略会忽略这个开关，所以方法 A/B 更可靠。

### 双显卡笔记本

- 确认笔记本没有开"集显模式"；有 MUX 开关的机型切到"独显直连"；
- 外接显示器如果接在主板上（而不是独显接口），画面仍由核显输出；
- 部分机器需要在 BIOS 里关闭 Hybrid/Optimus。

## 关于核显输出 + CMP 30HX 这类组合

CMP 30HX 是矿卡（TU116 核心，**通常没有显示输出**）。这种组合要分开看：

- 如果 Windows 的设备管理器 / 图形设置里**根本看不到这张卡作为图形适配器**，
  那浏览器没有可选的独显，任何网页都做不到"用 30HX 渲染"；
- 如果通过改版驱动让它以显卡身份出现，先按上面的方法 A/B 把浏览器指过去，
  再用 `chrome://gpu` 确认 GL_RENDERER 真的变成了它；
- 矿卡通常只有 CUDA/计算驱动，D3D/OpenGL/WebGL 支持不完整；即使强行选中，
  也可能无法创建 WebGL2 上下文，或直接回落软件渲染（`软件渲染` 标签就是这种情况）。

**这种情况下最现实的做法是让核显跑得动**：画质选"性能"（或保持"自动"），
世界分辨率从 0.65 起步、最低 0.5；关闭 MSAA、泛光、FXAA、实时阴影与程序化
细节，只保留墨线/排线。核显/软件渲染启动时还会把非碰撞装饰密度降到 40%
（芦苇、断篱、枯树；搜刮点与可碰撞物不受影响）。如果仍然卡，再把设置里的
"分辨率上限"降到 0.6 左右。

## 画质档位

| 档位 | MSAA | 泛光 | 实时阴影 | 程序化细节 | FXAA | 起始/最低世界分辨率 |
|---|---:|---|---|---|---|---:|
| 性能 | 0 | 关 | 关 | 关 | 关 | 0.65 / 0.50 |
| 均衡 | 2x | 4 级 | 1024² | 开 | 开 | 0.85 / 0.65 |
| 高清 | 4x | 5 级 | 2048² | 开 | 开 | 1.00 / 0.75 |

"自动"的规则：

- 启动时：核显/软件渲染 → 性能；独显 → 均衡；
- 运行中**只降不升**：连续 1 秒明显超标才把世界分辨率压一档，
  到本档下限后仍然超标才降一档画质。升清晰度请手动改画质或分辨率上限 ——
  自动升档会重建 RT/阴影图，反而造成周期性顿挫。

## 还能做什么

- 关闭其他占用 GPU 的标签页/程序（视频、地图、WebGL 页面）；
- 用窗口模式并减小窗口面积，像素数与 GPU 开销近似成正比；
- 不要用远程桌面/虚拟机里的软件渲染跑；
- 如果 `chrome://gpu` 里 WebGL 显示 "Software only" 或 "Disabled"，
  先解决浏览器的 GPU 加速问题，再谈游戏设置。

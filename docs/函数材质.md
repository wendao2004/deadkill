# 函数材质（手绘伪 3D）

> 2026-11-15。目标：在**不改变手绘伪 3D 画风**的前提下，把世界表面从"平涂色块"
> 提升到"一眼能读出石/木/金属/泥/植被"的层次。实现全在
> `client/src/ink.ts` 的墨线着色与 `client/src/render.ts` 的顶点色，不引入贴图、
> 不切 PBR。

## 为什么不用 PBR

`render.ts` 的 `realistic = false` 是当前画风的开关：写实 PBR 分支保留可回滚，
但默认走 `MeshToonMaterial` + `applyComicInk`。函数材质必须落在真正生效的
墨线层，否则改完是死代码（本项目已经踩过一次：PBR 湿度分支零像素差）。

## 1. 五族表面函数

`SURFACE_GLSL` 里每个函数只返回**固有色乘数**，不碰光照；世界坐标三平面投影，
按主导轴选平面，砖墙/地面自动换图案。所有参数都没有贴图，靠 hash/noise 生成。

| 家族 | 已有 | 本次新增 |
|---|---|---|
| 石（stone） | 墙面错缝砖、地面不规则石板、低frequency风化 | 石板缝里的苔藓绿、砖块崩边 |
| 木（wood） | 0.42m 板缝、拉长木纹、结疤 | 细锯齿痕、每 0.8m 一颗钉帽 |
| 金属（metal） | 17:1 拉丝、氧化锈斑、点蚀 | 0.30m 网格铆钉、掉漆露底 |
| 泥（mud） | 湿斑、水洼、砂砾 | 干裂纹（只在非湿区） |
| 植被（foliage） | 两档叶簇、冷暖变化 | 叶簇顶部的暖色高光 |
| 屋顶（高处朝上的木/金属） | —— | 木瓦片 / 金属瓦楞 + 搭接缝 + 缝边锈 |

采样预算：每个函数 3–4 次 `comicNoise2` + 若干 hash，仍在可接受范围；
性能档 `setInkDetail(false)` 时整块跳过。

## 2. 大面积变化（macro）

在表面细节之后、排线之前叠加：

- **颜料漂移（两个尺度）**：约 12m 的 `comicNoise2(world.xz * 0.085 + ...)` 与
  约 55m 的 `comicNoise2(world.xz * 0.018 + ...)` 按 65/35 叠加，在暖
  `(1.05,1.02,0.95)` 与冷 `(0.94,0.97,1.03)` 之间插值。近处打破"同一面墙
  反复平铺"，远处打破"整张图一个色调"。
- **贴地苔藓**：离关卡地面 0.15–1.9m 内、朝上的面更强，绿 `(0.78,0.90,0.66)`，
  最大 38% 混入。地面高度由 `setInkGroundY(level.groundY)` 传入，不写死 0。
- **地面草/砾石区块**：一张约 6m 的低频 patch 图，把"朝上且离地 2.4m 内"的
  表面分成草绿与砾石两块（`comicGrass` / `comicGravel`）。墙、屋顶、桌面不参与；
  采石场的石地也会长出零星杂草，与沼泽的泥地形成不同地貌。
- **积水**：雨后朝上的表面按 ~4.5m 的低频噪声出现冷色水膜
  `(0.60,0.71,0.82)`，强度由 `uComicWet` 驱动。它是**画出来的暗斑**，不是反射 ——
  手绘风格没有高光模型，镜面反射会立刻破坏画风。

这两层是"看起来更贵"的主要来源，但都不改变光照模型和 4 级色阶。

## 3. 顶点色：每块盒刷的手涂色差

关卡由几百个盒子合批而成。如果同材质共用一个固有色，远看必然是一块塑料板。
`buildLevel` 在合批前给每条盒刷写顶点色：

- 明度约 ±7%（植被 ±11%），冷暖约 ±3%（植被 ±5%）；
- 由位置哈希决定，**确定性**，同一 seed/同一张图每次一致；
- `MeshToonMaterial` 开 `vertexColors: true`，颜色在光照前乘进固有色；
- 地面、道具、武器不参与（没有 `color` 属性，material 也不开）。

采样展示：`?show=mats` 的五个立方体也带逐块色差，便于截图对比。

## 4. 逐实例色差（InstancedMesh）

关卡墙有顶点色，但树、栅栏、搜刮点、墓碑、枕木、GLB 自然资产是实例化的：
同一批共用一个几何与材质。这里用 `InstancedMesh.instanceColor` 给每个实例
写一个围绕 1.0 的乘数（`client/src/procedural-tint.ts`）：

- 树：每棵树的树干与所有枝条共用一个色差（`handTint(i, 0.14, 0.06)`），
  否则枝会像从别的树上借来的；
- 栅栏、搜刮点、大件道具、枕木：`tintInstances(mesh, count, 0.10–0.12, 0.04–0.05)`；
- GLB 树/石头/草：按实例序号哈希，草/植物幅度更大；
- **不消耗布局 rng**：色差只用实例序号哈希，同一 seed 的摆放位置不会因为
  加色差而改变；
- 墨线外壳不染色：它必须是纯黑。

## 5. 屋顶分支

同一个 wood/metal 函数按**离地高度 + 朝上**自动切换，不需要给盒刷打新标签：

- 木、`horizon > 0.5`、离地 2.2–10m → 瓦片：0.34×0.52m 错缝，下缘积苔；
- 金属、同样条件 → 石棉瓦：0.18m 波纹 + 2.4m 搭接缝 + 缝边锈；
- 10m 以上不切换：`?show=mats` 的材质展示台在 16m，必须保留素面以便对比；
- 2.2m 以下不切换：地板、桌面、铁轨顶面仍是木板/拉丝金属。

建筑外壳（`village-assets.ts`）不再使用 PBR 屋顶贴图：`loadVillageAssets`
只加载 GLB，材质由 `Renderer.loadVillage` 注入 toon/墨线。这样屋顶、门框、
阳台、烟囱与盒刷场景共享同一套色阶、排线与函数图案，也不会再出现
"一张写实瓦片贴图贴在卡通房子上"。

## 6. 湿度

`?wet=` / 天气修饰驱动：朝上的面压暗 26%，垂直面挂流痕，并按低频噪声出现
积水暗斑。见 `docs/QA与验收.md`。它与苔藓/颜料漂移叠加，暴雨局更暗、更绿、
更湿；死寂局更干。`wet=0/1` 同机位应产生可见差异（实测约 5% 像素）。

## 7. 水面

水面是独立的 `ShaderMaterial`（`props.ts` 的 `buildWater`），但同样走世界坐标
程序化函数：

- **波纹**：两道互相调制的正弦，硬边切级成水彩色块（原有）；
- **藻膜**：0.11 / 0.42 两个尺度的 value noise，暗绿 `(0.29,0.33,0.19)`，
  随时间极慢漂移；
- **浮萍**：3.8cm 网格哈希，2.5% 密度，18–34m 淡出，避免远处闪烁；
- **岸线**：`aMarsh` 刚过 discard 阈值的窄带混入浅泥色，水不会以硬 alpha 边结束；
- **雨圈**：0.6m 网格、每格独立相位，`uWet > 0.45` 才出现；死寂局水面是平的，
  骤雨局才有不断扩散的圆圈。`uWet` 由 `Renderer.setWetness` 同时喂给墨线层与水面。
- 仍然自己算 `FogExp2`，并做线性→输出色彩空间转换。

- 同一 URL 两次启动，像素差应在颗粒噪声范围内（`pnpm qa:diff`）；
- `wet=0/1` 应有可见差异，且排线/色阶仍在；水面机位在 `wet=1` 时应出现雨圈
  （实测约 1.1% 像素差异）；
- `__errors`/`kernelErrors` 为空。

## 9. 边界

- 不为材质下载贴图；`pbr-textures.ts` 的 Canvas 贴图只服务写实回滚分支。
- 不加逐像素法线扰动：会打散 4 级色阶，肉眼读成噪点，破坏手绘感。
- 细节距离 16–52m 淡出：程序化细节没有 mip 链，远处不淡会闪。
- 性能档：关闭细节噪声，只保留描边/排线/污渍/湿度；顶点色与色阶保留。

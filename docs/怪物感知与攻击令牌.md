# 怪物感知与攻击令牌

> 2026-11-15。对应手册 §5.5：视锥/LOS、`patrol → investigate → engage → search → patrol`、
> 攻击令牌、枪声听觉、同伴增援。实现集中在 `shared/src/ai.ts`（纯函数）与
> `server/src/world.ts`（物理、事件、令牌）。

## 1. 状态机

```
idle ──看见/听见──▶ investigate ──到达最后目击点──▶ search ──超时──▶ idle
  │                    │                              │
  └──看见玩家──────────┴──────────────────────────────┴──▶ chase ──够得着──▶ attack
                                                          │
                                                   Boss 冷却好 ──▶ special
```

- `idle`：在巢穴附近缓慢游荡；离巢超过 `HOME_ARRIVE_RADIUS` 时先回家，途中不索敌。
- `investigate`：去最后目击点或声源，速度是 `spec.speed × 0.78`。这个状态里**只认看得见的玩家**，
  不会被索敌循环重新锁回墙后的人。
- `search`：到达最后目击点 2m 内，绕着它慢慢转圈（半径 2.4m、0.55 rad/s），持续到 `searchUntilTick`。
- `chase` / `attack` / `special`：原有战斗状态，未改动。
- `dead`：终态。

`Monster` 上新增的字段：

| 字段 | 含义 |
|---|---|
| `lastKnownX/Z/Tick` | 最后一次**确认看见**目标的位置与 tick。没看见的 tick 不刷新。 |
| `lastKnownTargetId` | 这段记忆属于谁，防止旧位置串到新目标。 |
| `searchUntilTick` | 调查/搜索截止 tick。 |
| `noiseX/Z/Tick` | 服务端写入的枪声/同伴警报；AI 消费后清空。 |
| `losVisible/losTick` | 视线采样缓存。 |

## 2. 感知节流

- 视线采样间隔 `PERCEPTION_INTERVAL_MS = 120`（约 7 tick），按怪物 id 错开：
  `(tick + id % 7) % 7 === 0`。
- 目标进入 `attackRange` 后每 tick 复核，避免"贴脸了还看不见"。
- 候选扫描先算距离、再打 LOS：`aggroRange` 外的玩家不再消耗 Rapier 射线。
- 跟丢超过 `LOSE_TARGET_MS = 2500` 后放弃目标，转入 `investigate`；
  搜索总时长 `MONSTER_SEARCH_MS = 8000`。

## 3. 听觉与增援

- 玩家开枪：`World.tryFire` 在广播 Shot 事件后调用 `alertMonsters`，
  半径 `min(48, 10 + loudness × 14)` 米。刀不参与。
- 同伴增援：一只怪首次锁敌（`result.aggroed`）时，18m 内**尚未锁定目标**的怪
  收到同位置的噪声，转 `investigate`。
- 已有目标的怪不会被枪声叫走。

## 4. 攻击令牌

- 同时最多 `MAX_ATTACKERS = 3` 只怪可以出手；令牌租期 `ATTACK_TOKEN_MS = 1250`。
- 只有真的产出 `hit`/`shot` 的怪才占名额；到期自动释放，怪物死亡时立即释放。
- AI 侧通过 `senses.canAttack` 接收结果：被拒绝的怪保持 `attack` 状态、
  **不消耗冷却**，下一 tick 再申请。Boss 的冲锋/脉冲不受令牌限制。

## 5. 线上状态码

`MonsterStateCode` 追加 `Investigate = 5`、`Search = 6`。u8 字段本来就有空位，
**快照布局不变；协议版本已到 23（23 只加了 Names 名单包与 partyId/Loadout 尾段，未动快照）**。客户端暂时把 5/6 都映射到 chase 步态
（`client/src/monsters.ts`）：调查是在走，搜索是绕圈慢走，chase 步态会按实测速度
缩放摆臂，不会出现"站着滑行"。未知状态码仍然落到 idle 分支。

## 6. 验收

- `tests/ai.test.ts`：
  - Boss 冲锋 95 伤害必须在 `special` 窗口内结算（回归：曾被 `nextAttackTick` 挡在窗口外）；
  - `canAttack=false` 不出伤害、不消耗冷却，拿到令牌后正常出手；
  - 跟丢 → investigate → search；
  - 噪声 → investigate 并朝声源移动，噪声消费一次；
  - 20 tick 内远处目标的 LOS 采样 ≤ 4 次（节流生效）。
- `tests/protocol.test.ts`：状态码 5/6 是追加值，快照仍是 20 字节。
- 全量：`pnpm test` 239 通过。

## 7. 未做

- 视锥（正面 ±100°）：目前只有距离 + LOS。伺机从背后接近仍然会被"看见"，
  因为服务端的 LOS 不判朝向。加视锥需要把怪物 yaw 传进 `stepMonster` 或在
  `visible` 回调里比较玩家方位角；会改变潜行手感，留给玩法决策。
- 侦查动画：客户端复用 chase，没有专属的"张望/低头嗅"动作。
- 环境噪声（脚步/开门/乌鸦）：目前只有枪声与同伴警报。

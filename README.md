# DEAD KILL

一款跑在浏览器里的硬核 3D **PvPvE** 射击游戏，玩法参考《猎杀：对决》
(Hunt: Showdown)：1890 年代腐化沼泽，节奏慢、信息稀缺、一两枪就死、
声音是核心情报。

**当前状态：可完整游玩。** 服务端权威；5 张地图、6 把枪 + 猎刀、
4 种 Boss、线索 → 放逐 → 赏金 → 撤离的完整循环；双人组队与倒地救援；
天赋 / 配件 / 合同 / 跨局金币；画面为**手绘伪 3D**；自带截图、对比与
冒烟验收工具。

## 现在能玩什么

### 猎杀循环
- 每局约 15 分钟：调查 3 条线索 → 暴露血巢 → 放逐 Boss → 取赏金 →
  从 3 个撤离点之一带出。
- 一枪致命：伤害按部位、距离、穿透层数结算；倒地 30 秒可被队友救起。
- 死亡掉光本局战利品；成功撤离按身价折算金币，用于长期解锁。
- 每局天气修饰：死寂 / 浓雾 / 骤雨 / 虫潮，同时影响能见度、怪物密度、
  现金收益与表面湿度。

### PvE
- 沼泽行尸、猎犬、持枪行尸；Boss：屠夫、敲钟人、石心巨像、末班车长。
- 怪物有视野 / 视线判定、调查 → 搜索 → 追击状态、枪声听觉与同伴增援；
  同时最多 3 只出手（攻击令牌）。
- 可破坏巢穴、可打灭的油灯、捕兽夹、可开关的门、血月增援。

### 成长与配装
- 10 条天赋（解锁 + 三级升级）、4 种武器配件（2× 镜 / 消音器 /
  加长弹仓 / 加固枪托）、5 份合同、跨局金币。
- 主武器 6 把：温菲尔德杠杆、双管霰弹、短管双管、夏普斯神射手、
  柯尔特转轮、消音卡宾；外加猎刀。
- 双人组队：同队不友伤、倒地/爬行/处决、按住 E 救援。
- **塔科夫式改枪台**：瞄具 / 枪口 / 供弹 / 枪托四槽，兼容性与取舍（倍率、开镜、后坐、弹匣、换弹、重量、人机）；军械库内可旋转查看 3D 枪模，装配实时反映在模型与数值上。

### 大厅与房间
- 塔科夫式主页：中心四选一（进入沼泽 / 庇护所 / 设置 / 退出）；
  进入功能后是独立沉浸页，没有常驻导航/顶栏/底栏，只留左上角返回。
- 出击三步：**选择猎场（5 张地图） → 组队/配装 → 创建或加入房间**。
- 房间列表来自服务端 `/api/rooms`：显示地图、人数、阶段、剩余时间与名册；
  可一键创建房间，也可手输房号。房间按 matchId 隔离，其他玩家能直接看到并加入。
- 好友：本机好友码 + 在线目录（`/api/presence`），好友在线时可直接加入其房间；
  组队页同时显示好友与队伍名册。
- 队伍：邀请好友入队 → 队长选房 → 队长出击；队员自动一起加载进同一房间、
  强制同队，并共享出生点（首次出生与重生都用同一锚点）。
- 昵称：首次进大厅必须先报代号（`dk.nickname`）；服务端通过 `Msg.Names`
  全量广播名单，击杀播报、队友列表、房间名册统一显示这个代号。

### 画面与声音
- **手绘伪 3D**：4 级色阶、墨线、暗部排线、纸纹；写实 PBR 分支保留可回滚。
- HDR 管线：世界/武器分层渲染 → Bloom → AgX → 锐化 → FXAA。
- **函数材质**：石/木/金属/泥/植被五族世界空间表面函数，叠加宏观颜料漂移、
  贴地苔藓、积水、地面草/砾石、顶点色与实例色差、屋顶瓦片/瓦楞、
  水面藻膜/浮萍/岸线/雨圈。没有外部贴图。
- 命中反馈：粒子 + 按材质分池的弹孔贴花 + 光照脉冲 + 命中标记/方向弧 +
  分层声音 + 顿帧。
- 音频全部 WebAudio 合成：近/远、干/湿、室内/室外分层，HRTF 方位、
  遮挡低通与声速延迟。

### 工程与验收
- 服务端权威 + 客户端预测/和解 + 远端插值 + 延迟补偿；两端共用
  `shared/sim.ts`、`shared/character.ts` 与同一套 Rapier 物理。
- 协议：手写二进制，定长、小端；当前 `PROTOCOL_VERSION = 24`，
  60Hz tick、20Hz 快照。22 新增 `Msg.Names` 昵称名单（加入/离开时全量广播），
  击杀播报与队友列表读玩家代号，不再显示「猎人 #id」。
- QA：固定 seed / 画质 / 机位 / 冻结帧 / 无音频；`window.__stats()`；
  `pnpm qa:diff` 像素对比；`pnpm qa:smoke` 全路径冒烟。
- 鲁棒性：指针锁不可用时自动降级为移动鼠标转向；后处理链启动自检，
  失败或 `?postfail=1` 时回退 ACES 前向直出（`__stats().renderPath`）。
- `pnpm test` 264 条纯函数与集成测试。

## 技术栈

| 层 | 选型 | 一句话理由 |
|---|---|---|
| 渲染 | **Three.js r186** | 可 tree-shake、着色器可控、代码优先不需要编辑器 |
| 物理 | **Rapier3D 0.21**（WASM） | **客户端与服务端共用同一套**，否则预测必然漂移 |
| 网络 | **原生 WebSocket + 手写二进制协议** | 射击需要每 tick 上行输入，SSE/HTTP 做不到 |
| 服务端 | **Fastify 5**（作为宿主插件） | 与 WebLearning 现有后端同进程、同端口、同容器 |
| 客户端 | **纯 TypeScript + Vite** | 游戏循环与 Vue 响应式敌对；纯 TS 可嵌入任何宿主 |

完整决策依据（含被否决的方案与代价）见 [docs/技术栈决策.md](docs/技术栈决策.md)。
引擎内核（固定步换算、帧相位、确定性随机、共享层边界）见
[docs/内核.md](docs/内核.md)。接入宿主的步骤见
[docs/接入 WebLearning.md](docs/接入%20WebLearning.md)。

## 快速开始

```bash
pnpm install

# 终端 1：服务端（8787）
pnpm --filter @dk/server dev

# 终端 2：客户端（5173，已把 /ws 与 /api 代理到 8787）
pnpm --filter @dk/client dev
```

打开 http://127.0.0.1:5173 ，点「进入猎场」。单人即可打 PvE；
开**两个标签页**都进场，就能在同一张图里互相猎杀。

操作：`WASD` 移动 · `Shift` 疾跑 · `Ctrl` 蹲 · `空格` 跳（贴边可翻越）·
`左键` 开火 · `右键` 瞄准/重刀 · `R` 换弹 · `Q` 循环切枪 ·
`1/2/3` 主/副/刀 · `E` 搜索/救援 · `F` 包扎 · `M` 地图 · `Esc` 暂停/释放鼠标。

指针锁不可用或被浏览器拒绝（iframe sandbox / 权限策略 / 远程桌面）时，输入层会
自动降级为**移动鼠标转向**：键盘移动、开火、瞄准照常，只是不再锁定光标。

## 验收与截图

```bash
pnpm qa:diff before.png after.png      # 同机位像素对比，带阈值与退出码
pnpm qa:smoke                          # 主界面→入场→暂停→回大厅→再入场
```

固定场景示例：

```text
http://127.0.0.1:5173/?autostart=1&noaudio=1&seed=4207&q=quality
  &map=quarry-dust&show=lair&dt=0&shot=1
```

- `?dt=0` 冻结模拟，`?cam=x,y,z,tx,ty,tz` 固定机位，`?show=mats|fx|weapon|lair`
  切子系统/地点展示，`?wet=0..1` 固定湿度，`?reload=` 停在换弹关键帧。
- 等 `window.__shotReady === true` 再截图；`__stats()` 输出 calls/tris/tex/
  programs/分辨率/scale/FPS/内核错误数。
- 完整参数、诊断全局与验收清单见 [docs/QA与验收.md](docs/QA与验收.md)。

## 架构

```
input → game flow → player → weapon → enemies → fx → level/backdrop/materials
      → audio → hud → render
```

更新顺序由内核的依赖拓扑固定，不靠调用列表的书写顺序。几个关键约定：

1. **服务端是唯一裁判。** 客户端发意图（前后左右、视角、按键），位置、命中、
   伤害、掉落全在服务端算；前端改代码只能改自己屏幕。
2. **预测与服务端同源。** `shared/sim.ts` + `shared/character.ts` 被两端逐字共用，
   同一份常量、同一个 Rapier 版本。
3. **延迟补偿。** 开火时把其他玩家倒回"射击者屏幕上那一刻"再判射线；
   Rapier 回滚后必须 `propagateModifiedBodyPositionsToColliders()`。
4. **单系统可失败。** 内核给每个系统的每个阶段独立 try/catch，同一处只报一次；
   一个表现系统崩溃不会拖垮本帧其余系统。
5. **可验收才算完成。** 固定 seed + 固定机位 + 固定 dt + 截图 + `__errors` 为空。

## 目录结构

```
shared/          两端共用（不含 DOM、不含 node: 内置模块）
  kernel/        固定步时钟、依赖拓扑、同步事件总线、确定性 RNG、帧相位
  constants.ts   两端必须一致的常量与武器表
  protocol.ts    手写二进制协议（定长、小端、DataView）
  level.ts      关卡盒刷数据；maps/ 是 5 张地图与区域积木
  sim.ts / character.ts  移动模型与 Rapier 角色控制器
  hit.ts / penetration.ts  射线命中、散布、伤害衰减、穿透
  ai.ts          怪物感知、调查/搜索、攻击令牌（纯函数，服务端调用）
  matchDriver.ts 线索 → 放逐 → 撤离状态机
  lagcomp.ts / snapshotView.ts  延迟补偿与快照投影

server/          游戏服务端（Fastify 插件）
  world.ts       一个房间 = 一个 Rapier World + 9 段 tick 流水线
  worlds.ts      房间注册表与空闲回收
  game.ts        /api/game/status + /ws/game 握手

client/          Three.js 客户端
  game.ts        预测 / 和解 / 远端插值（注册进内核）
  render.ts      场景、关卡、武器层、HDR 后处理接线
  ink.ts         墨线/排线/世界空间函数材质
  props.ts       水面、芦苇、树、栅栏、群系装饰
  monsters.ts    怪物模型与程序化动画
  viewmodel.ts   第一人称武器姿态、换弹时间轴、弹簧通道
  audio.ts       全合成 WebAudio 音频
  qa.ts          URL 参数与诊断全局
  main.ts        DOM 接线（换成 Vue 组件只需改这一个文件）

tools/           qa-diff.mjs（PNG 像素对比）、qa-smoke.mjs（CDP 全路径冒烟）
tests/           264 条纯函数/集成测试（node --test）
docs/            设计、渲染、AI、QA、部署与评审文档
```

## 已知边界

- 怪物感知只有距离 + 视线，没有视锥；从背后接近仍会被发现。
- 步枪弹仓/枪机、霰弹枪折管炮管仍是合并几何；换弹时间轴目前驱动已暴露的
  杠杆/击锤/转轮，真正的"弹匣出→入"需要先拆模型组。
- 动态分辨率带回升滞回：只在测到 headroom（连续 5 秒低于 75% 预算）时升 0.05，
  升错封锁 60 秒；60Hz 垂直同步下通常不会触发回升。
- `?show=enemies` 还没有最小快照 harness；死亡/结算路径仍靠人工或录像。
- 金属石棉瓦屋顶分支已编译，但还没有定点验收截图；房顶瓦片分支已验证。
